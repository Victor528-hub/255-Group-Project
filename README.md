# 255-Group-Project

## Project topic

Store kiosk for end user to select
You will create a system for a Customer Kiosk.
The Customer will go to the kiosk and enter information to find out how much materials are needed for certain projects.
Painting the ceiling. The user enters in the length and width of the room and the type of paint. The system calculates the total square footage and determines how many cans of paint are needed based on the square footage and how much that type of paint covers.
Painting the walls of a room. The user enters the length, width and height of a room and the type of paint. The system calculates the amount of paint cans needed based on the measurements and the type of paint.
Installing floor tile in a room. The user enters the length and width of a room and the size of a tile. The system calculates how many boxes of tile are needed.
