# Store Kiosk

## Project Overview

The **Store Kiosk** is a customer-facing application being developed as part of the **SDC255 Final Project**.

The kiosk will help customers determine the materials needed for common home-improvement projects by entering measurements and selecting the appropriate materials.

## Project Objectives

* Create an easy-to-use customer kiosk
* Calculate materials needed for different projects
* Provide clear and accurate results
* Develop the application using Agile and Scrum methodologies
* Practice collaborative software development

## Project Requirements

The kiosk will support the following projects:

* **Painting a Ceiling**

  * Calculate the square footage of a ceiling
  * Determine the amount of paint needed

* **Painting Walls**

  * Calculate the square footage of the walls
  * Determine the amount of paint needed

* **Installing Floor Tile**

  * Calculate the square footage of a floor
  * Determine the amount of tile needed
