# Floor Tile Calculator

## Features Needed

## Customer Enters

- Floor Length
- Floor Width

## Program Calculates 

- Total floor square footage
- Amount of tile needed

## Program Displays 

- Total floor square footage
- Tile required

## User Interface

```text
---
        Floor Tile Calculator
Floor Length:
[           ] ft

Floor Width:
[           ] ft

        [ Calculate ]
        [ Reset ]

Floor Square Footage:____ sq. ft.
Tile Needed: ____ sq. ft.
---
```

## Calculation Rules

### Floor Square Footage
- Total floor area is calculated using:
    - Length*Width = Floor Square Footage

### Tile Needed
- Tile needed is based on the total Floor sq. ft.
- Waste Allowance: TBD
- Final tile amount should include any agreed waste percentage.

## Validation Rules
- Floor Length is required. 
- Floor width is required.
- All measurements must be greater than 0.
- The program should not calculate if measurements are invalid.
- The program should display an error message for invalid measurements.
